# Phase 2 — SQL for Data Analytics

This phase builds SQL skills for real-world Data Analytics.

## Topics Covered
- SELECT, DISTINCT, aliases
- WHERE, AND, OR, IN, BETWEEN, LIKE
- ORDER BY and LIMIT
- COUNT, SUM, AVG, MIN, MAX
- GROUP BY and HAVING
- CASE WHEN
- INNER JOIN and LEFT JOIN
- Multiple-table joins
- Date analysis
- String functions
- NULL handling
- Subqueries
- CTEs
- Window functions: ROW_NUMBER, RANK, LAG, LEAD, running totals
- Business analytics
- Views
- Indexes and EXPLAIN

## Database
Recommended: MySQL 8+

Database: `analytics_practice`

Tables:
- customers
- products
- orders
- payments
- reviews

## How to Practice
1. Run the SQL file once to create the database and sample data.
2. Run each section separately.
3. Change conditions and test your own queries.
4. Solve the 25 practice questions without copying the solved examples.
5. Save your answers in a separate file named `Phase-2-SQL-Practice-Solutions.sql`.

## Analyst Mindset
For every query ask:
- What business question am I answering?
- Which table contains the required information?
- Do I need a JOIN?
- Do I need GROUP BY?
- Is the result correct?
- What decision can this result support?
